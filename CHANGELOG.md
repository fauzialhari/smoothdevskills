# Changelog

This file records user-facing changes to SmoothDev Skills. Development changes
accumulate under **Unreleased**. Release preparation groups the approved notes
under their version and proposed release date; an entry alone does not establish
publication. Verify publication through the matching GitHub release and tag.
The skill's current version source is
`metadata.version` in [SKILL.md](skills/smoothdev-skills/SKILL.md); this change
record does not replace it.

## 0.1.0 — 2026-10-12

### Added

- Portable SmoothDev Skills instructions for discussing and recording the
  specification, confirming and documenting the plan, completing meaningful
  implementation units, and accepting combined final verification.
- Stage-specific approval and discussion choices, free-text feedback, and a chat
  fallback when a suitable native confirmation dialog is unavailable.
- Individually reviewed and approved commits, dependency impact explanations,
  approval invalidation after revisions, and preservation of developer changes.
- Procedures for potentially modifying Git hooks, revisiting earlier decisions,
  and recovering interrupted work without inferring missing approvals.
- Workflow specification, visual flowchart, and implementation plan.
- Public installation and invocation guidance for Codex, Claude Code, and Qwen
  Code, with DeepSeek support explained through the selected agent application.
- Version metadata, versioning policy, and boundaries for later release actions.
